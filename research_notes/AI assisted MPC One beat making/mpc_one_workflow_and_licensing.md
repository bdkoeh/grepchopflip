# Akai MPC One (original) + Windows 11 PC + open-source DAW + AI assistant: capabilities, workflows, tooling and licensing (as of 2026-10-24)

Scope note: Research focused per the coordinator's update on (a) the original MPC One (2020, 2 GB RAM) on MPC 3.x, (b) its USB audio/MIDI behaviour on Windows 11, (c) MPC file formats and open-source parsers/writers, (d) open-source DAWs and sync/bridge tooling that an AI assistant (Claude Code) on the PC could drive, and (e) the AI-music licensing landscape. ## Key Question 1: Which MPC 3.x firmware is current, and does the original MPC One get it in full? What does the One lack vs newer units?

### Takeaway
MPC OS 3.10 (released 2026-10-22) is current and free for all standalone MPCs and Force; the original MPC One is on Akai's official MPC3-supported list and has received every 3.x release (3.4 through 3.10). What it lacks is hardware, not firmware: 2 GB RAM / quad-core 1.8 GHz CPU, 8 standalone audio tracks, no Wi-Fi, no Bluetooth, no Ableton Live Control mode, and no battery; newer G2/Live III/XL units get 4-8 GB RAM, 16 audio tracks, up to 32 plugin instances and MPCe-pad-only modes.

### Inferences
- The original MPC One is a first-class MPC 3 citizen for feature parity; the practical ceiling is RAM (sample pool), CPU (plugin count, Super warp/Reverb Pro load) and the 8-audio-track cap. For a "just play" setup, use it mostly as a sequencer/sampler with internal instruments, and offload heavy processing to the PC.
- Because there is no Wi-Fi on the original One, on-device Splice browsing, Ableton Link and network firmware updates require the Ethernet-over-USB path (USB-to-Ethernet adapter in the USB-A port) or are simply done via the PC and SD/USB storage.

### Gaps
- Official 3.10 release notes PDF could not be read (403/binary); exact per-model exclusions beyond MPCe-pad features are unconfirmed.
- No measured data on MPC Stems processing time or success rate on 2 GB hardware.
- Whether the MPC3 FAQ's "MPC STEMS standalone compatibility*" asterisk excludes any model is not explained on the page.

## Key Question 2: MPC One USB audio/MIDI behaviour on Windows 11 (class compliance, channel counts, ASIO/WASAPI, Akai driver), and controller mode vs standalone for an automated PC workflow

### Takeaway
Akai lists the MPC One as Windows 11 "Supported" (USB, audio and/or MIDI tested) with the MPC 2.10.0.83+ driver package, and in controller mode the hardware presents to the PC as a USB MIDI + audio device plus file access; however, no Akai document found states the USB audio channel count for the original One, and community consensus is that it cannot stream its standalone multitrack mix to a DAW over USB — multitrack capture requires either controller mode (MPC software plugin multi-outs), exporting audio tracks/stems to SD, or analog outs into an external interface.

### Cited Findings
- Akai Windows 11 compatibility: MPC One, MPC Live II and MPC X are "Supported*" (asterisk: "Require MPC 2.10.0.83 software package and drivers or higher"); "Hardware support confirms testing passed for USB connection, as well as audio and/or MIDI communication"; listed software versions MPC 2.10.0.83 / 2.11 / 2.15.1, inMusic Software Center 1.1.0+ — [Akai Windows 11 Compatibility](https://support.akaipro.com/en/support/solutions/articles/69000802493-akai-pro-windows-11-compatibility)
- MPC 2.11 desktop/firmware added Windows 11 and macOS Monterey compatibility for MPC One, Live MkII, X, Live, Key 61 — [MPC 2.11 Update PDF](https://cdn.inmusicbrands.com/akai/M211PCVI/MPC%202.11%20Desktop%20Software%20and%20Firmware%20Update.pdf)
- Controller mode requires MPC 2.8+ software on Windows 10 / macOS 10.13+ and "a single driver"; in controller mode "you cannot access the internal drive" (browser shows the computer's drives) — [Akai MPC One FAQ](https://support.akaipro.com/en/support/solutions/articles/69000816149-akai-pro-mpc-one-frequently-asked-questions)
- The MPC drivers live in the "My Hardware" tab of the inMusic Software Center and must be installed before the hardware will interface with the computer; controller mode is entered from an empty project via MENU > Controller Mode — [Akai: transferring content](https://support.akaipro.com/en/support/solutions/articles/69000824436-akai-pro-mpc-series-transferring-content-to-and-from-the-mpc-via-a-computer)
- In controller mode, "the standalone functionality is disabled, but the MPC is able to connect to and communicate with the desktop software"; Gen-2 units need matching MPC 3 software and firmware versions — [Akai: stuck on 'Looking for computer'](https://support.akaipro.com/en/support/solutions/articles/69000837366-akai-pro-mpc-series-why-is-my-mpc-stuck-on-looking-for-computer-)
- MPC3 FAQ (older text still live): "MPC3 is currently only available on Standalone hardware... you can use controller mode with MPC 2.15.1 Desktop" — [Akai MPC3 FAQ](https://support.akaipro.com/en/support/solutions/articles/69000857771-mpc3-faq). As of 3.10 MPC 3 Desktop is out of beta (see KQ1). The MPC 3 Desktop public-beta FAQ lists Windows 10 (21H2) – Windows 11 (25H2), 2 GB free disk — [Akai MPC 3 Desktop beta FAQ](https://support.akaipro.com/support/solutions/articles/69000869156-akai-pro-mpc-3-desktop-public-beta-faq)
- Reverse-engineering of the MPC Live (same RK3288/2 GB platform family as the One): Buildroot Linux; closed-source JUCE/ALSA app; in controller mode a script flips a USB multiplexer so "the audio and control devices connect to the host instead of the RK3288", and the unit "appears to a computer as a USB class-compliant MIDI and audio interface, plus USB access to internal storage"; AK4621 codec on main I/O, AK4413 4-channel DAC for extra output pairs; SSH disabled but enable-able via serial console — [MPC Live Internals (N. Nisbeth)](https://niklasnisbeth.gitlab.io/mpc-internals/)
- Sound On Sound (MPC Live review): "When connected via USB to your computer the MPC appears as an audio and MIDI interface" — [SOS MPC Live](https://www.soundonsound.com/reviews/akai-mpc-live)
- Community: "the MPC cannot operate simultaneously standalone in USB host mode and in USB device mode" (single USB controller); "live multitrack USB audio into my DAW is not possible, apparently"; MPC-side recording capped at "8 audio tracks" — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1875574); [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1845897); [MPC-Forums "Multi Track Recording into a DAW"](https://www.mpc-forums.com/viewtopic.php?t=215924&p=1864892). Recommended workarounds: physical outs into a multi-input PC interface; class-compliant mixer/interface with multiple outs attached to the MPC; or MPC Software + controller mode — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?f=48&t=193079); [MPC-Forums 2.10 thread](https://www.mpc-forums.com/viewtopic.php?p=1836538)
- In controller mode (MPC plugin in a DAW), SOS describes routing "multiple outputs from the plug-in into your DAW's mixer, or print to tracks" — [SOS MPC One](https://www.soundonsound.com/reviews/akai-mpc-one)
- Standalone-side I/O expansion: the MPC Series supports class-compliant USB audio interfaces "to expand the input and output capabilities of the device when in standalone mode", with an option for up to 32 in/out; no drivers needed; interface-specific caveats — [Akai class-compliant interface support](https://support.akaipro.com/en/support/solutions/articles/69000859194-mpc-series-class-compliant-audio-interface-support). Forum reports of Focusrite 18i20 behaviour depending on the 32 I/O toggle — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1898926)
- MIDI over USB in controller mode: one user never got USB MIDI to connect to DAWs and used a 5-pin DIN interface instead (2022, anecdotal) — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1836443). Akai's plugin-transport guide: in Ableton set Control Surface "Akai Force MPC" and the MPC One ports for in/out; MPC Play/Stop do not drive the host by default and must be MIDI-mapped — [Akai plugin transport setup](https://support.akaipro.com/en/support/solutions/articles/69000855239-akai-pro-mpc-series-mpc-plugin-transport-setup-in-ableton); [Akai multi-MIDI ports](https://support.akaipro.com/en/support/solutions/articles/69000804431-akai-pro-mpc-series-configuring-midi-ports-for-multi-midi-control)
- Windows audio stack: Windows 11 has no built-in ASIO; Akai's own guides recommend ASIO4ALL when using a computer's internal soundcard; Akai's Ableton Link guide says on Windows "Link will not work without the ASIO4ALL driver" — [Akai Link setup](https://support.akaipro.com/en/support/solutions/articles/69000814493-akai-pro-mpc-series-force-ableton-link-setup-and-tutorial); [MPC Renaissance/Studio guide (ASIO4ALL advice)](https://cdn.inmusicbrands.com/akai/MM28M20/MPCRenaissance-MPC%20Studio-UserGuide-v2.8.pdf)

### Inferences
- For the stated goal (MPC jam -> PC capture with minimal setup), two viable architectures emerge: (A) Standalone MPC + 1/4" outs -> a cheap class-compliant 2-in interface on the PC, with 5-pin or USB MIDI clock; this preserves the standalone "just play" feel but yields a stereo mix (per-track separation then comes from MPC's own "export tracks as audio" to SD). (B) Controller mode with MPC 3 Desktop (now out of beta) as a VST3 inside the DAW, which gives per-track multi-out to the DAW mixer and PC-side plugins, but moves processing to the PC and disables standalone features/internal drive.
- The Akai Windows driver is likely a WDM/ASIO driver for the MPC's own stereo I/O; the One's USB audio to the PC is almost certainly limited to its physical stereo in/out (the hardware only has one codec pair plus CV DACs), consistent with the forum consensus — but this count is not confirmed by Akai.

### Gaps
- No Akai document states the USB audio channel count the original MPC One exposes to Windows in controller mode, nor whether the Akai driver is ASIO, WDM or both. Treat "stereo in/out" as unconfirmed.
- Whether MPC 3 Desktop (post-beta) is free for existing One owners, and whether controller mode with the original One now requires MPC 3 Desktop vs 2.15.1, was not stated in sources found.
- Reliability of USB MIDI from the One to Windows DAWs: only one old negative anecdote found.

## Key Question 3: MPC file formats (.xpm/.xpj/.xal/.sxq/.progression) and open-source parsers/writers

### Takeaway
MPC 3 projects (.xpj) are gzip-compressed JSON with a 5-line text header (reverse-engineered, firmware 3.7+), and sequences live as .sxq files in the `[ProjectData]` folder; keygroup/drum programs are .xpm. A handful of small, mostly MIT/Unlicense GitHub projects read/write .xpm and MPC Sample .xpj, plus ConvertWithMoss (LGPL-3.0) for multisample -> MPC keygroup conversion; none is a complete, maintained MPC 3 .xpj/.sxq writer, and .xal has no public documentation.

### Cited Findings
- `.xpj` (MPC 3, firmware 3.7+): "a gzip-compressed JSON file with a 5-line text header" (lines: ACVS, firmware version, object type, encoding, platform); content under top-level `data` key, `formatVersion: 2`; documentation reverse-engineered from 18 project files and the 3.7 User Guide, author warns it "is likely to contain errors"; repo has 3 commits, 6 stars, no licence shown — [kurtjcu/MPC-project-file-definitions](https://github.com/kurtjcu/MPC-project-file-definitions); [xpj-format subfolder](https://github.com/kurtjcu/MPC-project-file-definitions/tree/main/xpj-format)
- Forum confirmation the format changed with MPC 3 beta 3.4: "Xpj are now gzipped, unzip and you'll ... get standard json rather than xml"; sequence data "all handled in the XPJ as json"; `ProjectData` folder next to a project holds sequences in `.sxq` — [MPC-Forums "Project File format changed"](https://www.mpc-forums.com/viewtopic.php?p=1886903); [MPC-Forums ".xpj extractor?"](https://www.mpc-forums.com/viewtopic.php?p=1841271)
- Akai's own transfer guidance: copy both the `.xpj` and its matching Project Data folder to the same folder; load via Browser > Places; expansions copied from `ProgramData\Akai\MPC\Content` (Windows, hidden files shown); "The MPC One, One+ and Key 37 will not mount an external USB thumb drive to your desktop when connected in controller mode" but SD cards do mount — [Akai: transferring content](https://support.akaipro.com/en/support/solutions/articles/69000824436-akai-pro-mpc-series-transferring-content-to-and-from-the-mpc-via-a-computer)
- MPC3 FAQ: MPC3 projects "may not be directly compatible" with Desktop; workaround "export all tracks as audio files"; MPC2 projects load into MPC3 with track/program merging rules — [Akai MPC3 FAQ](https://support.akaipro.com/en/support/solutions/articles/69000857771-mpc3-faq)
- Open-source tools found on GitHub:
  - [smfarrelly/mpc-keygroup-builder](https://github.com/smfarrelly/mpc-keygroup-builder) — "MPC Instrument Factory" for "MPC 3 standalone systems"; Python 3.12 (uv); MIT; 233 commits, v0.1.0 "software-preview", 0 stars; builds pitched keygroups with velocity layers from WAVs, builds/colours/audits drum programs, inspects XPM programs and MPC 3 XPJ projects read-only, generates drum/bass/chords/melody MIDI, plans checksum-verified SD-card deployments; CLI `mpc-tools`, `mpc-program-color`.
  - [tarikcampos/MPC-Sample-Toolkit](https://github.com/tarikcampos/MPC-Sample-Toolkit) (MPCTK) — Python 3.11+, MIT, 41 commits, 3 stars; reads/writes gzip `.xpj`, preserves unknown fields, generates chromatic/scale pad layouts, WAV injection, auto `_[ProjectData]` packaging; targets the MPC Sample device's `.xpj` and still needs an existing XPJ as a structural template.
  - [ResistanceIsUseless/mpcsample](https://github.com/ResistanceIsUseless/mpcsample) / [WorldLinkStudio/mpcsample](https://github.com/WorldLinkStudio/mpcsample) — web/desktop kit maker that exports `.xpj` for MPC Sample hardware (licence/activity not checked).
  - [intelliriffer/MPC-KeyGroupBuilder](https://github.com/intelliriffer/MPC-KeyGroupBuilder) — scripts that create keygroup programs for MPC/Force from a folder of samples; [intelliriffer/EXS-CONVERT](https://github.com/intelliriffer/EXS-CONVERT) converts Logic EXS to MPC/Force keygroups, SFZ etc. (licence/activity not checked).
  - [B0ss-M/XPM-version-2](https://github.com/B0ss-M/XPM-version-2) — XPM repair/edit scripts (details not checked).
  - plule/mpc_valet — browser tool: drop samples, set root notes, download XPM — [MPC-Forums announcement](https://www.mpc-forums.com/viewtopic.php?t=213721&p=1849494)
  - [liotier/AkaiMPC](https://github.com/liotier/AkaiMPC) — vanilla JS, Unlicense, 458 commits, 23 stars; chord-progression generator/finder exporting MPC `.progression` files; `.xpm` MIDI program files for Roland MX-1/TR-8/VT-4.
  - [git-moss/ConvertWithMoss](https://github.com/git-moss/ConvertWithMoss) — LGPL-3.0, Java, Windows packaging scripts and a CLI properties file present; the author's site lists "Akai MPC Keygroups (*.xpm)" among supported formats; forum user: SFZ->MPC conversion "worked like a charm" — [Mossgrabers.de](https://www.mossgrabers.de/Software/ConvertWithMoss/ConvertWithMoss.html); [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1850195); recent releases 19.x–20.3 — [newreleases.io](https://newreleases.io/project/github/git-moss/ConvertWithMoss/release/20.3.0)
- Legacy formats the One can import: .AKP, .ALL, .IPT, .PGM, .PRJ, .SND, .MID, .SEQ, .APS, .50k, .50s (MPC5000/4000/3000/2500/1000/500) — [Akai MPC One FAQ](https://support.akaipro.com/en/support/solutions/articles/69000816149-akai-pro-mpc-one-frequently-asked-questions)
- Custom-firmware precedent exists only for legacy hardware (m45k Open500 for MPC500, Oct 2026), not for the One — [Synth Anatomy](https://synthanatomy.com/2026/10/m45k-open500-custom-akai-mpc500-firmware.html)

### Inferences
- The most robust AI-assistant automation path is generating/editing `.xpm` programs (XML in MPC 2.x era; the keygroup-builder repos target MPC 3 XPM) and WAV folders, then deploying them to an SD card or USB stick that the MPC browses — this avoids the under-documented `.xpj`/`.sxq` internals entirely. Generating full MPC 3 projects programmatically is feasible but risky (unknown fields, "UNCONFIRMED" docs); MPCTK's "preserve unknown fields + template" approach is the safest pattern to copy.
- No library exists for `.sxq` sequence files; the practical route for sequence transfer is standard MIDI files (the MPC imports .MID) or the MPC's own Ableton Live Set / MIDI export.

### Gaps
- `.xal` format: no documentation or tooling found anywhere.
- `.sxq` internals: only "exists in ProjectData" is confirmed.
- Last-commit dates for the GitHub repos were not visible in fetched pages; activity is inferred from commit counts/release tags only.
- Whether MPC 2-era XML `.xpm` and MPC 3 `.xpm` differ materially was not established.

## Key Question 4: Getting content onto the MPC One fastest (Splice on-device, Expansions, USB/SD, project transfer, Ableton Live Set export) and MPC software automation features

### Takeaway
For an original MPC One without Wi-Fi, the fastest, least fragile path is PC-side preparation and SD-card (or USB-stick) transfer; on-device Splice requires network via Ethernet adapter and has a documented inaudible-sample bug; Ableton Live Set export exists (MENU > SAVE > Ableton Live Set) but has been reported buggy across MPC 3 betas; MPC's chop (Threshold/Regions/BPM/Manual), BPM auto-detect, audio-track auto-warp and (paid) stems do the "let the machine do it" sample prep.

### Cited Findings
- Splice integration launched for Force 3.0.2 / MPC 2.5 (Live/X) with Wi-Fi browsing from the touchscreen and a free 3-month Splice trial; the MPC One's browser also has "a direct integration with the Splice online sample subscription service" — [Akai newsflash](https://www.akaipro.com/newsflash-splice-integration); [SOS MPC One](https://www.soundonsound.com/reviews/akai-mpc-one); [Splice x Akai page](https://splice.com/partners/akai)
- Known bug: samples downloaded via the built-in Splice option "may become inaudible after a point. This has been confirmed as a bug, and we are working closely with Splice"; workaround is the Splice desktop app -> USB/SD/SSD — [Akai: Why can't I hear my Splice samples?](https://support.akaipro.com/en/support/solutions/articles/69000822776-why-can-t-i-hear-my-splice-samples-). ## Key Question 5: Sync, bridges and open-source DAW/scripting stack on Windows (Ableton Link, MIDI clock, OSC, virtual MIDI, Ardour/Zrythm/LMMS/Reaper)

### Takeaway
Ableton Link is natively supported by MPC standalone (Sync Receive/Send options are MIDI Clock, MTC, Ableton Link) over Wi-Fi/Ethernet — which on the original One means a USB-to-Ethernet adapter plus Akai's network driver — and on the PC side the open-source Link SDK (GPLv2+) and Carabiner (GPL-2.0, Windows x64 binary, TCP port 17000) let scripts join a Link session; among open-source DAWs only Ardour (9.x, Feb–Aug 2026 releases, Windows builds, OSC + Lua control) is production-ready, while Zrythm 2 and LMMS 1.3 are alphas; Reaper is the pragmatic non-FOSS fallback with OSC (port 8000 by convention) and Python ReaScript, and the only proper Windows virtual-MIDI loopback (loopMIDI/teVirtualMIDI) is free but proprietary.

### Cited Findings
- MPC Sync Receive/Send options: MIDI Clock, MIDI Time Code, Ableton Link — [Akai multi-MIDI control article](https://support.akaipro.com/en/support/solutions/articles/69000804431-akai-pro-mpc-series-configuring-midi-ports-for-multi-midi-control); Link setup: Preferences > Wifi or Ethernet, then Sync field = Ableton Link; Windows note that Link "will not work without the ASIO4ALL driver" in Ableton — [Akai Link setup](https://support.akaipro.com/en/support/solutions/articles/69000814493-akai-pro-mpc-series-force-ableton-link-setup-and-tutorial)
- Akai's Live Control guide (MPC X/Live) requires the "Akai Network Driver" and describes connecting via a USB-to-Ethernet adapter with Ethernet enabled in Preferences — [Akai MPC/Ableton Live Control Setup Guide PDF](https://cdn.inmusicbrands.com/akai/MPCAbletonLiveControlSetupGuide-v1.0.pdf). MPC One users report network options arriving with firmware 2.10 and needing the USB-to-Ethernet adapter (Mac-only anecdotes) — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1830304). A forum tip: Link via the Akai network driver over Ethernet "syncs well" (c. 2021) — [MPC-Forums](https://www.mpc-forums.com/viewtopic.php?p=1836426). Ableton recommends Link over MIDI clock whenever available — [Ableton help](https://help.ableton.com/hc/en-us/articles/209071149-Synchronizing-Live-via-MIDI)
- Ableton Link SDK: header-only C++ library, "dual licensed under GPLv2+ and a proprietary license", source on GitHub — [CDM](https://cdm.link/ableton-opening-link-everyone-starting-today/)
- Carabiner (Deep Symmetry): GPL-2.0 (+BSD-3 components), binaries for Windows x64/macOS/Linux/RPi, listens on 127.0.0.1:17000 (`--port`), commands `status`, `bpm`, `beat-at-time`, `enable-start-stop-sync` (Link 3+); 131 commits, 187 stars — [Deep-Symmetry/carabiner](https://github.com/Deep-Symmetry/carabiner). Python client LinkToPy — [bdyetton/LinkToPy](https://github.com/bdyetton/LinkToPy); used by TidalCycles — [TidalCycles Link doc](https://userbase.tidalcycles.org/Link_synchronisation.html)
- loopMIDI uses the virtualMIDI (teVirtualMIDI) driver; listed as "Proprietary and Free" — [AlternativeTo](https://alternativeto.net/software/loopmidi/about); [Tobias Erichsen](https://www.tobias-erichsen.de/?p=45). No maintained open-source Windows virtual-MIDI loopback driver surfaced in search.
- Ardour 9.0 released 2026-02-05 for Linux/macOS/Windows (piano-roll windows, MIDI cue/clip editing, multi-touch on Windows/Linux); 9.2 hotfix 2026-02-24 fixed a Windows crash; later 9.x point releases through mid-2026 (9.7 June; 9.8.0 reported Aug 25, unverified) — [Ardour 9.0](https://discourse.ardour.org/t/ardour-9-0-released/112897); [Ardour 9.2](https://discourse.ardour.org/t/ardour-9-2-released/113007); [Synthtopia](https://www.synthtopia.com/content/2026/02/13/ardour-9-now-available-for-linux-mac-windows/); [Softpedia](https://www.softpedia.com/get/Multimedia/Audio/Audio-Editors-Recorders/Ardour.shtml). Ardour can be scripted via OSC, websocket or the Lua shell; headless builds exist but are not distributed and command-line export is a known weak point — [Ardour forum](https://discourse.ardour.org/t/ardour-without-gui/83372); [Ardour forum](https://discourse.ardour.org/t/how-do-i-load-and-play-an-ardour-session-from-the-command-line-headless/100304); [Ardour OSC manual](https://git.ardour.org/ardour/manual/blame/commit/180d48425296a9a92e04e44255eb6ed3d6dc736e/_manual/22_using-control-surfaces/01_controlling-ardour-with-osc.html)
- Zrythm 2.0: C++/Qt rewrite; alpha since 2026-05-31, "pre-release software intended for testing only", Windows x64 and experimental ARM64EC builds — [Phoronix](https://www.phoronix.com/news/Zrythm-2.0-Alpha); [Zrythm v2 alpha download](https://www.zrythm.org/en/download-v2-alpha.html); [BPB](https://bedroomproducersblog.com/2026/08/06/zrythm-2-alpha/)
- LMMS: stable remains 1.2.2 (2020); 1.3.0-alpha.2 (Sept 2026) warns of crashes and non-backward-compatible project files; Windows 10/11 x86-64-v2 only — [AlternativeTo news](https://alternativeto.net/news/2026/9/lmms-releases-1-3-0-alpha-2-bringing-the-long-awaited-daw-s-update-closer-to-stable/); [LMMS releases](https://newreleases.io/project/github/LMMS/lmms/release/v1.3.0-alpha.2)
- Reaper: scripting (ReaScript incl. Python via Preferences > Plug-ins > ReaScript), OSC (Preferences > Control/OSC/Web; community convention listen port 8000, reply 9000) and web interface (8080) make it "an obvious choice for building all sorts of integrations"; several open-source MCP servers already wrap Reaper for LLM agents (e.g., itsuzef/reaper-mcp, Scythe MCP) — [DEV Community](https://dev.to/maxim_radugin/extensible-control-of-reaper-via-osc-and-scripts-2n27); [Scythe MCP setup](https://glama.ai/mcp/servers/@yura9011/scythe_mcp_reaper/blob/c3cb9086a57f9aff11fe486ede61420851a3f736/scythe_mcp/reascript/install.md); [reaper-mcp OSC server](https://glama.ai/mcp/servers/@itsuzef/reaper-mcp/blob/de78d180f7a37dfe94cff007861bc90cb4f8fd9f/osc_mcp_server.py)
- Community DAW-controller setup for the One: remotify's Ableton guide and MPC-Tutor's "Using the Akai MPC with Ableton Live" book cover MIDI mapping and sync — [remotify](https://remotify.io/ableton-controllers/akai-mpc-one-ableton/); [MPC-Tutor look-inside PDF](https://www.mpc-tutor.com/assets/shop/demos/Using-The-Akai-MPC-With-Ableton-Live-Look-Inside.pdf)

### Inferences
- Simplest low-setup sync for a One + Windows PC: MPC as master sending MIDI Clock over USB (or 5-pin via the PC interface) to the DAW, which just records; Link is nicer but needs the Ethernet adapter and, for Ardour/Reaper, a bridge such as Carabiner (neither DAW has native Link).
- An AI assistant can realistically automate: Ardour via OSC/Lua or Reaper via OSC/ReaScript (arm tracks, set tempo, start/stop recording, render), file-level MPC program generation, and SD deployment. It cannot automate anything inside the MPC's standalone UI (closed firmware, no API) beyond MIDI/Link messages.
- Of the FOSS DAWs, Ardour 9 is the only one safe to recommend for daily use on Windows 11 today; Reaper remains the cheapest reliable scripted fallback (licence cost not researched here).

## Key Question 6: AI music/sample tools' licensing and the Suno/Udio litigation status (as of October 2026)

### Takeaway
Splice's generative tools (Variations, Craft; Magic Fit pending) and its 3M-sample catalog are explicitly licensed for commercial use with creator payouts, making Splice the clearest legal source of AI-assisted sample material; Suno grants paid (Pro/Premier) subscribers assignment of output rights but only for downloaded tracks, Udio has disabled all downloads since the UMG deal, and litigation continues: UMG/Sony v. Suno and Sony v. Udio remain active (new recordings added mid-2026), Warner settled with both, UMG settled with Udio, a GEMA ruling against Suno landed in Germany (July 2026), and the AFM union sued UMG/Warner over the settlements.

### Cited Findings
- Splice announced (2026-04-15) AI tools Variations (Splice Sounds plugin), Craft (Splice INSTRUMENT) and Magic Fit (slated summer 2026), built on 3M+ human-made licensed samples; "Splice confirmed that all output from the tools is licensed for commercial use"; creators paid when their sound is used as source and when a variation is downloaded — [Music Business Worldwide](https://www.musicbusinessworldwide.com/splice-launches-ai-tools-that-compensate-sample-creators/). Splice also partnered with ElevenLabs on AI products — [Billboard](https://www.billboard.com/pro/splice-partners-with-elevenlabs-create-new-ai-products/)
- Splice catalog licence: "royalty-free license for every sound that you download"; certified licence documents for up to 25 samples for distributors; may not redistribute Splice sounds as samples/loops — [Splice licensing FAQ](https://intercom.help/splice-b7a2d5b83f2e/en/articles/8652642)
- Suno Terms (revised 2026-08-10, effective 2026-09-03): for paid tiers "Suno hereby assigns to you all of its right, title and interest in and to any Output owned by Suno" subject to the Terms; "You may not commercially exploit Output that has not been downloaded by you through an approved channel"; download allotments depend on tier; free/basic users agree to "lawful, personal and non-commercial purposes" only; Remixes are jointly owned and non-commercial "regardless of your subscription tier" — [Suno Terms](https://suno.com/terms).

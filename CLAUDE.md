# Using GCF

For processing songs and selecting sample material, read [docs/INSTALL.md](docs/INSTALL.md)
and [docs/AGENT_USAGE.md](docs/AGENT_USAGE.md). Use the checkout's `.venv/bin/gcf`, JSON
results and bounded queries. Humans judge musical usefulness. No skill-install command
is implemented or required.

For modifying this repository, follow [AGENTS.md](AGENTS.md) and the project records it
names. Historical design documents are not the current CLI contract.
